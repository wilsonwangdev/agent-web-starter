# 维护 Agent Web 示例

先读根目录 [AGENTS.md](../../../AGENTS.md)、[项目清单](../../../package.json)和[贡献指南](../../../CONTRIBUTING.md)。版本、命令和实际能力从仓库读取，不在技能中维护副本。

按任务读取上下文：

- 聊天、工具或状态生命周期：读[架构](../../../docs/architecture.md)，沿界面、SDK 消息流和 Worker 追踪输入、执行、结果与取消；保持状态唯一归属和入口组装职责。
- 页面、主题与移动交互：读[设计](../../../docs/design.md)，复用语义变量、UI 包、语言资源与既有提供器，验证真实浏览器和生产页面中的受影响状态。
- 模型服务或托管：读[配置与部署](../../../docs/deployment.md)，凭据留在服务端，分别说明演示、模拟、真实服务和实体设备证据。
- 创建派生项目：读[起步说明](../../../docs/start.md)，先确定项目身份、工具权限和业务流程，再替换示例。

使用 AI SDK 已提供的消息、传输和工具能力；项目代码只维护业务适配与界面。演示模式明确呈现固定流程与真实只读工具执行，真实模式按显式配置工作；错误不能用演示回答掩盖。

改变行为时执行适用检查，并同步受影响的架构、设计或配置说明。项目技能只维护触发入口与任务约束；行为试用见[项目技能场景](../../../docs/agent-evaluation.md)，运行统计、凭据和个人信息留在被忽略材料中。公开源码保持独立，不依赖作者本机或其他仓库的相邻检出；提交、推送和部署沿用任务授权。
