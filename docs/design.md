# 设计约定

界面服务一条清楚的流程：输入任务、观察回复和工具结果、继续对话。首页直接开始，已有会话可以继续；连接方式与工程配置通过设置和文档解释，不成为每次提问的前置学习任务。

## 交互与能力说明

演示模式在首页及对话中清楚标注。固定回复不能呈现为模型对任意内容的真实分析；工具结果区分输入、执行中、成功和失败。真实模型未配置时说明缺口，不借演示结果掩盖错误。

输入区保持一个主要动作，生成期间提供取消。等待、失败、取消与重试保留可编辑内容；已有消息继续可读。切换会话、新建与删除分别表达，导航不隐式清空记录或让旧请求抢回页面。

工具调用以简洁、可展开的结果呈现；先展示对用户有意义的名称和结论，再按需查看参数与结构化数据。访问口令、原始协议和开发配置不混入普通回复。错误说明下一步可执行的操作。

## 视觉基础

颜色、字体、间距、字号和圆角以 `src/design-tokens.css` 为维护源；应用样式与组件只消费语义变量。正文使用 Geist 与中文系统字体，代码使用 Geist Mono，字体随构建提供。背景、中性表面和文字建立层级，强调色用于焦点与选择状态。

基础 Button、Select、Dialog 来自本仓库的 shadcn Radix 源码包；来源与本地适配见[许可说明](licenses/shadcn-ui.md)。组件样式使用 `ui:` 前缀，按应用变量映射主题，不引入第二套全局重置或品牌值。应用覆盖与基础组件保持明确样式层序，实际生产构建同时验证字体、弹层位置与焦点。

外观模式、主题配色、密度和语言分别管理。自定义强调色保持正文、主要操作及禁用状态可读；存储失败时保留当前状态并提示。首屏外观初始化在应用模块运行前完成，组件挂载后的检查不能替代刷新与初次绘制验证。

初始化等待不展示产品宣传文案。HTML 提供与导航、标题区和输入区衔接的中性骨架，启动样式直接从 HTML 加载并消费同一组设计变量；语言、外观与密度偏好在首帧应用。React 就绪后立即接管，历史恢复只在现有外壳内保留内容骨架，不增加最短展示时间。轻微脉动在减少动态效果时停用，强制颜色下保留可见轮廓。入口或主模块失败时提供主动重新加载，禁用脚本时明确提示；恢复不清空用户记录，不自动刷新。

## 语言、移动与可访问性

界面资源按语言分别维护，由 i18next 注册并检查键结构。会话内容保持原文；切换界面语言不改写消息。日期与数字按当前区域格式呈现。

布局覆盖手机、平板和桌面；长文本、代码及工具数据局部滚动，不撑宽整页。输入和主要操作保留触控尺寸，考虑动态视口、安全区与软键盘。设置弹窗限制视口高度并可内部滚动，关闭后返回实际触发入口；嵌套选择列表先关闭，再关闭弹窗。

控件提供可访问名称、原生语义与可见键盘焦点。状态同时用文字或图标表达，不只依赖颜色。覆盖强制颜色、减少动态效果、长译文和文字放大；行为验证与实际截图分别提供证据。

PWA 提供安装清单、图标与独立窗口基础，安装由使用者主动触发；具体能力与边界见[部署说明](deployment.md#安装与上线验收)。浏览器模拟不能替代实体手机安装与软键盘验收。
