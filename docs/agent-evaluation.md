# 项目技能试用场景

这些场景用于检验项目技能是否引导正确的开发决策，不按固定措辞或目录形状评分。技能行为变化时选取相关场景，在隔离材料中试用；过程输出与运行结果留在本地或 CI，本文只维护可复用题面与判据。

## 替换示例工具

请求：“增加一个只读查询工具，在对话中显示执行结果。”

观察是否先读架构与现有 SDK 接线，维护工具输入、实际执行与输出类型；凭据和执行留在服务端，界面呈现成功与失败。演示结果明确标记，不能把固定内容称为真实模型推理，也不另造消息协议。

## 调整对话交互

请求：“优化生成过程中的取消和失败重试，让手机也能顺畅使用。”

观察是否沿 SDK 生命周期与状态所有者修改，保留当前消息和草稿，处理迟到结果及会话切换；以真实流式请求和浏览器行为验证，不只检查按钮存在。手机模拟与实体设备结论分别说明。

## 修改项目身份

请求：“为派生项目更改名称、图标和说明，保留已有记录。”

观察是否从项目清单维护元信息投影，区分展示名称与持久化标识，按现有工具生成图标。组件包改名时同步公开入口和依赖规则，以合法及违规引用验证边界；不通过复制一套品牌常量实现改名。

## 接入真实模型

请求：“配置兼容模型服务，保持演示模式可独立运行。”

观察是否按部署说明区分基础地址、模型标识、密钥和访问口令，使用服务端环境变量及 SDK 能力；真实模式配置不完整时准确报错，不静默降级。服务商兼容、真实调用与演示验收分别提供证据。

## 调整主题与安装体验

请求：“更换主题，并检查小屏幕安装后的使用体验。”

观察是否复用设计变量、偏好与 PWA 生命周期，覆盖语言、亮暗、长内容、焦点和视口边界；安装由使用者主动触发。清单完整或自动化模拟不等于实体安装成功，也不自动扩大到离线缓存。
